# Emoji Mood Predictor 

An AI that reads a sentence and predicts which emoji matches the mood.

## How it works
- Uses a pre-trained AI model to detect emotions in text
- Maps emotions to emojis using a dataset of 4,700+ emojis
- Achieves ~85% accuracy on emotion detection

## How to run
1. Open the `.ipynb` file in Google Colab
2. Upload the `emoji_df.csv` file when prompted
3. Run each cell in order

## Built with
- Python
- HuggingFace Transformers
- Google Colab
